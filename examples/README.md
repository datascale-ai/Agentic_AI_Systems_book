# Examples and engineering assets

本目录存放第八篇综合项目和第九篇工程实践共用的示例与工程资产，包括参考实现、测试夹具、实验配置、运行清单和部署演练材料。

建议按章节或项目组织：

```text
examples/
├── ch34/              # 综合项目与参考架构
├── ch36/              # 参考实现、配置与可复现环境
├── ch37/              # 单元、集成和端到端测试
├── ch38/              # 回归评估、故障注入和可观测性
└── ch39/              # 部署演练、持续交付和发布材料
```

每个资产包建议包含 `README.md`、`src/`、`tests/`、`fixtures/`、`run_manifest.yaml` 和许可证说明。正文只保留关键代码片段，完整资产通过本目录或发布包提供。
