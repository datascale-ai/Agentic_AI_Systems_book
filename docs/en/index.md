# Agentic AI Systems: From Large Language Models to Real-World Agents

## Book Overview

This site is the English translation workspace for a practical and research-oriented book on agentic AI systems. It follows the Chinese source manuscript and covers model interaction, planning, tools, memory, multi-agent systems, runtimes, evaluation, governance, testing, and deployment practice.

> The repository currently provides a stable chapter scaffold. Authors will replace the placeholders with reviewed prose, figures, experiments, and runnable code.

## Reading paths

- **Foundations:** Parts I–III for concepts, model interaction, planning, and action.
- **Systems:** Parts IV–VI for state, memory, multi-agent systems, and runtimes.
- **Production:** Parts VII–IX for evaluation, safety, governance, testing, and deployment.
- **Projects:** Chapter 34 and Part IX for a reproducible engineering lab.
